# 空港 要件定義

本格的な空港（小・中・大）の要件。1マス＝16m。街の建物と同じ実寸で作る。

## 1. 種類と規模

| | 小 | 中 | 大 |
|---|---|---|---|
| 参考 | ロンドン・シティ空港（街なかの空港） | チューリッヒ規模の地方空港 | ミュンヘンのハブ空港 |
| 滑走路 | 約1,500m×1本 | 約2,500m×1本、平行誘導路と高速脱出誘導路 | 3,000m級×平行2本（間隔は4kmマップに収まるよう約1.0〜1.3km） |
| 敷地の目安 | 約20×110マス | 約30×175マス | 約80×220マス |
| 置けるマップ | 2km・4km | 4kmのみ | 4kmのみ |
| 機材 | ATR72（約27m）、A220・E190（約35〜38m） | A320・B737（約38m）中心、一部ワイドボディ | A320〜B777（約65〜74m）・A350 |
| 搭乗 | 搭乗橋なし（歩いて乗る） | 搭乗橋6〜10 | 本館＋サテライト、搭乗橋20以上 |

- 2kmマップで中・大を置こうとしたら「このマップには大きすぎます（大マップ用）」と出す。
- メニュー名：空港（小）／空港（中）／空港（大）。マス数は2行目に表示。

## 2. 見た目（ヨーロッパの現代空港）

- ターミナルは木とガラスの大屋根（ミュンヘンT2、マドリードT4のような）。
- 管制塔：高く、印象的な形。空港のランドマーク。
- 屋上の展望デッキ：人が飛行機を見ている。
- 空港ホテルとオフィス棟：ターミナル前（ミュンヘンのエアポート・センターのような）。
- 貨物・整備地区：貨物ターミナル、格納庫（中に機体）、燃料タンク、空港の消防署。
- 路面の表示：滑走路番号、白いしま（ピアノキー）、接地帯標識、中心線、黄色い誘導路中心線と停止位置、駐機スポットの誘導線、構内道路。滑走路の周りは芝生。
- 夜の灯火（実際の規格どおり）：
  - 滑走路の縁は白、手前の端は緑、奥の端は赤、中心線は白と赤。
  - 誘導路の縁は青、中心線は緑。
  - 進入灯（滑走路の手前に伸びる光の列）とPAPI。
  - エプロンの照明塔、ターミナルのガラスの明かり（窓の明かりの新しい色に合わせる）、管制塔の赤い障害灯。

## 3. 飛行機

- 離着陸：離陸滑走→上昇→街の上空を飛んでマップの外へ。着陸はマップの外から進入→フレア→接地。
- タキシング：滑走路⇔誘導路⇔駐機スポット。搭乗橋への横付け（搭乗橋が伸びる）とプッシュバック。
- 地上の車両：バス、給油車、トーイングカー、荷物車が駐機場を動く。
- 塗装：架空の航空会社4〜6社（白地に尾翼と線の色を変える）。実在の会社は使わない。
- 便数：人口と空港の利用者数で増え、画面の飛行機も増える。深夜は便が減る。
- 貨物機も飛ぶ。

## 4. アクセス

- 空港駅：ターミナルの下に駅を置く。鉄道・地下鉄・高架鉄道・モノレールの線路を引き込めば、乗客が使う。
- 都市高速・高速道路から直接入れる：空港のアクセス道路を高速につなげる（空港専用ランプ）。
- ターミナル前：高架の出発ロビー道路、地上の到着口、駐車場ビル。
- 敷地の入口は一般道にもつなぐ（ほかの公共施設と同じ）。

## 5. シミュレーション

- 商業・オフィスの需要が上がる。規模が大きいほど強く効く（今と同じ仕組みを3段階に）。
- 航空貨物：ハイテク工業の貨物の一部を優先して空港へ運ぶ。その分、マップの外へ向かうトラックが減る。
- 騒音：滑走路の向きに沿って伸びる範囲で、周りの地価が下がる。
- 建設：いつでも建てられる（人口などの条件なし）。
- 費用：規模に合わせて高く。目安は小§80,000・中§300,000・大§1,000,000。着陸料などの収入もある。維持費と汚染も規模に応じて決める。

## 6. 置き方

- 縦横4方向の回転に加えて、斜め（45°）にも置ける。
- 海の上にも置ける：自動で埋め立てて岸壁で囲む（羽田・関空のように）。費用は高くなる。
- 置く前のプレビューで、置けない場所を赤く表示し、理由を出す（傾き、水、道路、建物など）。

## 7. 今の空港

- 今の空港（小）（大）は、すでに建っているものはそのまま残して動かす。メニューからは消す。
- 取り壊して、新しい空港を置き直せる。

## 8. 重さ（iPhone）

- fpsを落とさない。路面の表示は平らな板、灯火は1つの描画でまとめて描く（インスタンス）。
- 飛行機と地上の車両もインスタンスで描き、同時に動く数は控えめにする。
- 巨大な敷地でも、画面の外の部分は描かない（区画の範囲を正しく）。
- 空港ありとなしで、描画回数とポリゴン数を測って確かめる。
