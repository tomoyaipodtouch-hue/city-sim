最終更新：2026-11-03（段階4b の内容を反映）
状態：**確定**

## 1. 概要

| 項目 | 内容 |
|---|---|
| ジャンル | 都市開発シミュレーション |
| 基準とするゲーム | SimCity 4 Deluxe（本編＋Rush Hour）の**ゲームの仕組み** |
| 動作環境 | スマホのブラウザ（iPhone 13 の Safari を基準） |
| 画面の向き | 横向き固定 |
| 言語 | 日本語 |
| タイトル | Pocket Metro |

### 1.1 方針

- SC4 Deluxe のゲームの仕組み（ゾーン、需要、建物の成長、通勤経路による交通、公共サービス、経済）を忠実に再現する
- 名前、建物のデザイン、UI、音楽などの見た目はオリジナルにする。SC4 の素材は使わない
- 段階的に開発する（「10. 開発の段階」を参照）

### 1.2 対象外

- U-Drive-It（車両を運転するミッション）
- コミュニティ製の Mod の機能（例外：ラウンドアバウトは採用）
- 元に戻すボタン
- 季節と天気
- 時代設定
- BGM
- 水道管を引くための地下の画面

## 3. 描画と見た目

| 項目 | 内容 |
|---|---|
| 描画方式 | 3D（WebGL2） |
| カメラ | 斜め見下ろし。90°ごとに4方向へ回転できる。地面に対する角度はズームに合わせて変わり（近く 48°〜遠く 72°）、設定で全体を −30°〜+15° ずらせる |
| ズーム | なめらかに拡大・縮小。一番近づくと人や車の細部まで見える |
| 昼と夜 | 時間が進んでいる間、約8分で1日が回る（設定で「昼だけ」「夜だけ」も選べる）。朝夕は赤く、夜は窓や街灯が光る |
| 影と水面 | 影を表示する。水面は反射させる |
| 細かい要素 | 木、公園、街灯、駐車場などを自動で配置する |

### 3.1 建物

- 形、高さ、窓、屋根、外壁の色と素材、看板などを組み合わせて**自動生成**する
- ゾーンの種類×密度×所得層ごとに数十種類、**全体で数百種類**の見た目を用意する
- 敷地は 1×1〜4×4マス。公共施設やランドマークはもっと大きいものもある
- 建設中は工事中の様子を表示する。空き家になると見た目が荒れる
- 建物の雰囲気は複数用意できる設計にする。**最初はアメリカの都市風のみ**

## 5. 道路と交通網

### 5.1 道路の種類

| 種類 | 車線 | 斜め | 特徴 |
|---|---|---|---|
| 街路（Street） | 狭い2車線 | ○ | 安く、速度は遅い。住宅街向け |
| 一般道（Road） | 2車線 | ○ | 標準的な道路 |
| 一方通行 | 2車線・一方向 | ○ | 交通量が多い |
| 大通り（Avenue） | 4車線、2マス幅 | ○ | 交通量が多い。中央分離帯あり |
| 高架高速道路 | 4車線 | ○ | 最も速い。インターチェンジでのみ乗り降りできる |
| 地上の高速道路 | 4車線 | ○ | 高架より安い。地面を分断する |

- 通行方向：**右側通行**
- 大通りは、引いた線を右側の車線とし、その左側に反対車線を自動で作る（それぞれ一方通行）

| 種類 | 制限速度 | 容量（台/日・1マス） | 建設費（1マス） |
|---|---|---|---|
| 街路 | 30 km/h | 900 | §10 |
| 一般道 | 50 km/h | 2,400 | §20 |
| 一方通行 | 50 km/h | 3,000 | §25 |
| 大通り | 60 km/h | 3,600（片側） | §30 × 2マス |
| 高架高速道路 | 100 km/h | 7,000（片側） | §120 × 2マス |
| 地上の高速道路 | 90 km/h | 6,500（片側） | §60 × 2マス |
| ランプ | 50 km/h | 3,000 | §600（1か所） |

### 5.2 道路の引き方

- 指でなぞって、縦・横・斜め45°の8方向に引く
- 引いている間は完成予定の線と費用を表示し、指を離すと確定する
- 途中でキャンセル位置に指を動かすと取り消せる
- 坂道：高低差があっても引ける。急すぎる場合は自動で地面を削る（費用がかかる）
- 橋：水の上に道路を引くと自動で橋になる。まっすぐな橋のみ、最大24マス、両端は陸地。建設費は6倍
- トンネル：山を越えるときに自動で作る（今後）

### 5.3 交差点

- 普段は交通量に応じて自動で設定する（少ない：信号なし、中くらい：一時停止、多い：信号）。プレイヤーは「情報」ツールで交差点をタップして、次の項目を変更できる
  - 制御方式：信号なし／一時停止／信号
  - 信号の時間配分
  - 右折レーン・左折レーンの追加
  - 進行方向の制限（右折禁止、左折禁止、直進のみ）
  - ラウンドアバウト（環状交差点）

### 5.4 高速道路のインターチェンジ

- 決まった形の部品を置く方式
  - ランプ（出入口）：高速道路の横のマスに置く。高速道路の車線から降りて、一般の道路につながる
  - ダイヤモンド型：高速道路をタップすると、一般道が立体交差し、4本のランプでつながる。ランプは高速道路から斜めに3マス離れたあと並走し、一般道とのT字路につながる（高速道路に沿って約14マス、横に約12マスを使う）
- 立体交差の坂：一般道は、またぐ場所の前後最大3マスかけて少しずつ上がる（土留めの壁で支える）
- 一方通行は、起点と終点の路面に進む向きの矢印を描く
  - クローバー型：地上の高速道路と高架の高速道路が交差する場所をタップすると、8方向の乗り換えを作る。右折は外側の直結ランプ、左折は内側のループ（270°）。ランプの道筋は、周りの空いているマスから45°より急に曲がらない最短の道を探して決める（交差点から前後11マスの範囲を使う）

### 5.4.1 道路の階層

- 道路は「地上」と「上空」の2つの階層を持つ
- 高架高速道路は上空を通るので、下に道路を通せる
- 地上の高速道路と一般の道路が交差する場所は、一般の道路が自動で上空に上がる（立体交差）
- 高速道路は一般の道路と直接つながらない（ランプを使う）

### 5.4.2 道路の見た目

- カーブはなめらかに描き、センターラインも曲がって続く
- 行き止まりは、街路は丸い転回場、ほかの道路は丸い端
- 交差点は角を丸くする。信号・一時停止の場所には停止線、信号の場所には横断歩道を描く。信号のない交差点では、優先道路のセンターラインが交差点の中も続く
- 種類の違う道路は、幅をなだらかに変えてつなぐ
- 歩道と縁石を描く。高速道路は歩道の代わりにコンクリートの壁

### 5.5 公共交通

| 種類 | 内容 |
|---|---|
| バス | バス停は道路のマスに重ねて置く（もう一度タップすると外せる）。周辺の住人が利用する。路線は自動で決まる（道路を車の約0.75倍の速さで走る）。待ち時間は平均5分 |
| 鉄道（地上） | 駅でのみ乗り降りできる。平均60km/h、待ち4分。道路とは、まっすぐな場所で直角にだけ交差できる（踏切）。水の上には引けない |
| 高架鉄道 | 高さ8m。平均55km/h、待ち3.5分。道路や水の上を通せる |
| 地下鉄 | 地下鉄のツールを選ぶと、地上が透けて地下の線路が見える画面になる。平均55km/h、待ち3分 |
| モノレール | 高さ11m。平均75km/h、待ち3分。高架鉄道とは高さが違うので交差できる |
| フェリー | 旅客用（2×2）とカーフェリー（3×3）。水辺に、道路に接するように置く。同じ水域にある同じ種類の乗り場どうしが航路で結ばれる（旅客 25km/h・待ち8分、カーフェリー 20km/h・待ち10分）。水域がマップの端まで続いていれば、カーフェリーで隣の都市へ行ける |
| 空港 | 小（4×10）と大（7×16）。商業とオフィスの需要が上がる。周りは騒音で地価が下がる。電力が必要。飛行機が離陸する |
| 港 | 4×4。水辺に置き、水域がマップの端まで続いている必要がある。工業の需要が上がり、トラックの荷物の行き先になる |
| 貨物駅 | 3×2。線路と道路に接するように置き、線路がマップの端まで続いている必要がある。トラックの荷物の行き先になる |
| 隣の都市への鉄道 | 鉄道・高架鉄道がマップの端まで続いていれば、電車で隣の都市へ通勤できる |

- 水辺の施設は、桟橋や岸壁が水のほうを向くように置く。川岸の斜面にも造成して置ける

## 6. 交通シミュレーション

### 6.1 移動の発生

| 目的 | 出発地 → 目的地 |
|---|---|
| 通勤 | 住宅 → 職場（商業・工業） |
| 買い物 | 住宅 → 商業（サービス業）。30分以内の店に行く |
| 通学 | 住宅 → 学校 |
| 貨物 | 工業 → マップの端（隣の都市）。港・鉄道の貨物駅は段階3で追加。トラックは乗用車2.5台分として数える |

### 6.1.1 交通手段の選択

- 住人は、車・徒歩・公共交通（乗り換えを含む）の中から、所要時間がいちばん短いものを選ぶ
- 車を持たない人の割合：低所得40%、中所得15%、高所得5%。車を持たない人は、公共交通か徒歩しか使えない
- 歩く時間は、人が長く歩くのを嫌うことを表すため、実際の2倍として扱う
- 鉄道・高架鉄道・モノレール・地下鉄は、原則として複線（上り線と下り線の2本）。電車は進む向きの右側の線路を走る
- 駅・バス停は、道路に接したマスで乗り降りする。駅は線路にも接している必要がある
- 公共交通の線路と駅には維持費がかかり、1日の乗客1人あたり月 §1 の運賃収入がある

### 6.2 計算方法

- 1日の平均で計算する。朝夕のラッシュは見た目だけで表現する
- 交通手段の選択：所要時間を比べて、車・バス・鉄道・地下鉄・モノレール・徒歩から選ぶ。お金持ちほど車を好む
- 経路の選択：所要時間が最短の経路を選ぶ
- 渋滞：道路ごとに容量がある。交通量が容量に近づくほど速度が落ちる。交差点の設定も所要時間に影響する
- 影響：通勤時間が長い地域は人気が下がる。ひどいと建物が空き家になる
- 性能対策：住人を1人ずつではなく建物単位でまとめて計算する。1回の更新で全部ではなく少しずつ計算する

### 6.3 表示

- 交通量に比例した台数の車を走らせる。渋滞すると車列ができる
- 分析ツール：交通量マップ、渋滞マップ、経路照会（ある建物の住人がどこを通っているか）

## 7. 都市シミュレーション

### 7.1 ゾーン

| 区分 | 種類 |
|---|---|
| 住宅 | 低所得（$）、中所得（$$）、高所得（$$$） |
| 商業 | サービス業（$／$$／$$$）、オフィス（$$／$$$、中・高密度のみ） |
| 工業 | 農業（低密度のみ）、汚染型工業、製造業、ハイテク産業（教育と一緒に段階4で追加） |

- 密度：低・中・高の3段階。ゾーンを指定するときに選ぶ

### 7.2 需要と建物の成長

- 需要は種類ごとに計算し、グラフで表示する。人口と雇用のバランス、税率、周辺の環境で決まる
- 需要があり、その土地の魅力が高いと建物が建つ。さらに条件がよくなると、より大きな建物に建て替わる
- 都市の人口が増えると、高層ビルが建つようになる（最大の階数：人口2,000未満は6階、6,000未満は12階、15,000未満は22階、30,000未満は36階、60,000未満は55階、100,000未満は80階、それ以上は110階＝400m級）
- 高層ビルの形は、ねじれた塔、先細りの八角形、段々の塔、円筒形、斜めに切った屋上、ふたごの塔と連絡通路、香港のような十字形の高層集合住宅などから選ばれる
- 公園：小さな公園（1×1）、遊び場（1×2）、緑道（1×3）、広場（2×2）、運動場（2×3）、池のある庭園（2×3）、大きな公園（3×3）。細長い公園は、長い辺が道路に面する向きに自動で回る
- ゾーンの密度を上げたり、建物が古くなったりすると、より大きな建物に建て替わる
- 水道がない場所には、低密度の小さな建物しか建たない
- 土地の魅力を決める要素：地価、汚染（大気・水・ゴミ）、犯罪、通勤時間、公共サービス、公園、景色（水辺や高台）

### 7.3 インフラ

| 種類 | 内容 |
|---|---|
| 電力 | 発電所を建て、送電線を引く。隣り合った建物、ゾーン、道路を通して自動でつながる（道路をまたいで隣の区画に届く）。発電所は石炭火力、ガス火力、石油火力、原子力、風力（高い場所ほど発電量が多い）、太陽光の6種類 |
| 水道 | 給水施設（ポンプ、給水塔）を建てる。水道管は道路に沿って自動で通る |
| ゴミ | 埋立地、焼却場、リサイクル施設 |

### 7.4 公共サービス

| 分野 | 施設 | 働き |
|---|---|---|
| 警察 | 交番（1×1）、警察署（3×2） | 範囲内の犯罪を減らす。犯罪は人口が増えるほど起きやすく（6,000人で最大）、密度が高く地価が低い場所ほど多い |
| 消防 | 消防分署（2×2）、消防署（3×3） | 範囲内の火災の危険を減らす（工業は危険が高い） |
| 医療 | 診療所（2,500人）、病院（12,000人） | 範囲内の住人の健康を守る。受け入れ人数が足りないと効き目が下がる。大気汚染は健康を下げる。健康度から平均寿命が決まる |
| 教育 | 小中学校（1,200席）、高校（1,500席）、大学（5,000席、街全体）、図書館 | 住人を子ども・大人・高齢者に分けて教育水準を記録する。子どもの水準は学校の席の足り具合で上がり、大人の水準は子どもの水準と大学で上がる |
| ゴミ | 埋立地（月6,000）、焼却場（月9,000、大気汚染あり）、リサイクルセンター（月4,000減らす） | 住人1人あたり月0.9、雇用1あたり0.6のゴミが出る。処理しきれないと魅力と地価が下がる（ゴミの量が月3,000を超えると本格的になる） |

- 犯罪・火災の危険・ゴミは住宅と商業の魅力を下げ、医療と教育は上げる
- ハイテク産業（工業の中・高密度）は、大人の教育水準が70を超えると需要が出る。オフィスも教育水準が高いほど来やすい
- 予算は部門（警察・消防・医療・教育・公共交通・ゴミ処理）ごとに 0〜150% で設定し、施設ごとにも調整できる。60%未満が6か月続くと、3か月のストライキが起きる

### 7.5 時間

- 速度：停止／遅い／普通／速い
- 「普通」でゲーム内の1か月＝現実の30秒

## 8. 経済とイベント

| 項目 | 内容 |
|---|---|
| 税金 | ゾーンの種類と所得層ごとに税率を設定する |
| 予算 | 部門ごと（警察、消防、教育、医療、交通、インフラ）と施設ごとに設定する。予算が少ないとサービスの質が落ち、ストライキも起きる |
| 条例 | 14種類（禁煙、地域見回り、夜間外出制限、カジノ、省エネ、節水、分別収集、大気汚染防止、排出ガス規制、相乗り、観光、工業誘致、火災報知器、無料健康診断）。施行には人口の条件があり、人口に応じた毎月の費用がかかる（カジノは収入） |
| 借入 | §25,000／§50,000／§100,000 を10年返済で借りられる（最大5件）。年利4〜9%で、資金がマイナス、赤字、借入が多いほど高い。全額をいつでも返せる |
| 市長評価 | 0〜100。税率、犯罪、大気汚染、通勤時間、失業、ゴミ、電力・水不足、医療、教育、財政、条例、記念施設から毎月決まる。住宅の需要に少し影響する。理由の内訳をアドバイザーの画面で見られる |
| アドバイザー | 財政、都市計画、交通、安全、健康・教育、環境・インフラの6人が、街の状態に応じて助言する。新しく出た「問題」はニュースでも知らせる |
| 記念施設 | 市長公邸（人口2,000・評価55）、市長の銅像（人口5,000・評価70）、博物館（人口8,000・評価55・大人の教育水準90）、市役所（人口10,000・評価50）、スタジアム（人口30,000・評価60）。それぞれ1つまで。サンドボックスでは条件なしで建てられる |
| ニュース | 画面の下に流れる |
| 災害 | 火災、竜巻、地震、隕石、火山噴火、暴動、空想の災害（巨大ロボットなど）。**プレイヤーが起こしたときだけ発生する** |
| ゲームモード | 難易度3段階（初期資金と需要の強さが変わる）、サンドボックス（お金が無限） |

## 9. 操作と画面

### 9.1 タッチ操作

| 操作 | 動作 |
|---|---|
| 1本指でドラッグ | ツールを選んでいないときは地図を動かす。選んでいるときは道路を引く、ゾーンを塗るなど |
| 2本指でドラッグ | ツールを選んでいても地図を動かせる |
| ピンチ | ズーム |
| 2本指でひねる | 回転（90°ごとに止まる） |
| タップ | 建物を選んで情報を表示する |

### 9.2 画面構成（横向き）

UI は**左と下にまとめる**。

```
┌──────────────────────────────────────────────┐
│ [ツール] │                                     │
│  道路    │                                     │
│  ゾーン  │            （街の画面）              │
│  電力    │                                     │
│  水道    │                                     │
│  公共施設│                                     │
│  交通    │                                     │
│  地形    │                                     │
│  取り壊し│                                     │
├──────────┴───────────────────────────────────┤
│ 資金 人口 日付 ▶速度 │需要グラフ│データ表示│メニュー│UIを隠す│
│ ニュース：〇〇地区で渋滞が悪化しています……      │
└──────────────────────────────────────────────┘
```

- 左：ツール。選ぶと、その中の種類が左の列の右側に開く
- 下：資金、人口、日付、時間の速度、需要のグラフ、データ表示、メニュー（予算、条例、アドバイザー、設定）、UI を隠すボタン、ニュース
- 「データ表示」と「メニュー」は、押すと画面の下から一覧が開く
- データ表示の種類：交通量、公共交通、地価、汚染、犯罪、火災の危険、教育、医療、ゴミ、電力、水道、ゾーン（ゴミは建物ごとに出る量を色の濃さで、処理しきれずに残る割合を緑〜赤で表す）
- UI を隠しているときも、画面の隅に戻すための小さなボタンだけ残す

### 9.3 音

- 効果音のみ。プログラムで合成する

### 9.4 保存

- 端末に保存する（IndexedDB）
- 自動保存と、複数の保存スロット
- 保存データをファイルとして書き出し、読み込める

## 10. 開発の段階

| 段階 | 内容 | 遊べること |
|---|---|---|
| **1. MVP** ✅ | 地形（自動生成）、街路と一般道（8方向）、住宅・商業・工業の低密度ゾーン、電力、水道、需要、建物の成長、通勤の交通、税金と予算、保存、画面構成 | 小さな街を作って育てられる |
| 2a. 道路と密度 ✅ | 一方通行、大通り、橋、中・高密度、オフィス | 大きな街を作れる |
| 2b. 高速道路と交差点 ✅ | 高架高速道路、地上の高速道路、ランプ、ダイヤモンド型インターチェンジ、交差点の設定、貨物・買い物の移動、道路の見た目の作り直し | 大きな街で渋滞と向き合える |
| 3a. 公共交通 ✅ | バス、鉄道、高架鉄道、モノレール、地下鉄、駅、交通手段の選択 | 交通網を作り込める |
| 3b. 水運と空 ✅ | フェリー、空港、港、貨物駅、隣の都市への鉄道 | 都市の外とつながる |
| 4a. 公共サービス ✅ | 警察、消防、医療、教育（年齢層ごと）、ゴミ、ハイテク産業、部門・施設ごとの予算、ストライキ | 都市経営として遊べる |
| 4b. 都市経営 ✅ | 条例、借入、アドバイザー、市長評価、記念施設 | 市長として街を運営できる |
| 5a. 昼と夜・地形の編集 ✅ | 昼と夜（自動・昼だけ・夜だけ）、夜の窓と街灯、地面を上げる・下げる・平らにする、通勤の計算の高速化 | 街の雰囲気と地形を作り込める |
| 5b. 災害 | 火災、竜巻、地震、隕石、火山噴火、暴動、空想の災害 | 災害と向き合える |
