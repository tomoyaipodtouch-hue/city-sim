# 高速鉄道 要件定義

ヨーロッパの高速鉄道（ICE・TGV・ユーロスターのような）を街に入れる。

## 1. 車両

- 白や銀の流線型。ヨーロッパ風の架空のデザイン（実在の会社のロゴや塗装は使わない）。
- 実寸（先頭車の長い鼻、1両約25m、8〜12両編成）。

## 2. 線路

- 普通の鉄道とは別の、高速鉄道専用の線路。
- 高架が基本で、街の外では地上にも引ける。
- 引き方は普通の線路と同じ（縦横・斜めにドラッグ）。
  - 曲がる所は、大きな半径のカーブで自動的になめらかにする。
  - 急な曲がりは引けない（理由を表示）。
- 見た目：高架橋、架線柱と架線、防音壁（必要な所）。

## 3. 駅

- 駅は1種類（4×14マス）。ターミナル駅と中間駅を共用する。
  - 線路の端につなぐとターミナル駅（列車はここで折り返す）、途中につなぐと中間駅（止まる列車と通過する列車）として働く。
  - 出入口は駅の両側（長い辺の両方）につく。
- 駅前広場とバスターミナル：駅の前に広場、タクシー乗り場、バス乗り場。

## 4. ゲームの中の役割

- マップの外の街と結ぶ：線路をマップの端まで引くと、ほかの都市からの乗客が来る。商業・オフィスの需要と観光が上がる。
- 駅の周りの地価が上がる：大きな駅の周りが繁華街になる。

## 5. 駅のデザイン

- 空港と同じ木とガラスの雰囲気。ただし屋根は波型ではなく、すっきりした箱型。
- ホームを覆う箱型のガラス屋根（木の天井・細い柱）。駅舎も木とガラスの箱。両側の出入口にそれぞれ庇。

## 6. 決定事項（追加）

- 乗り換え：鉄道・地下鉄・高架鉄道・モノレールは、それぞれ自分の駅を高速鉄道の駅の隣に置き、連絡通路で乗り換える（高速鉄道の駅の中には、ほかの路線のホームは作らない）。
- 費用：高め。線路は高架鉄道の約3倍、ターミナル駅§300,000、中間駅§100,000。運賃収入があり、乗客が多いと黒字。
- 街の中の移動：駅が2つ以上あれば、街の中の遠い移動にも使う。
- 騒音：線路沿いの地価が少し下がる。住宅地の横では自動で防音壁がつき、影響が小さくなる。
- 列車：8〜12両編成。利用者が多いほど本数が増える。通過する列車と止まる列車がある。
- 路線：線路がつながれば自動で走る（今の鉄道と同じ）。
