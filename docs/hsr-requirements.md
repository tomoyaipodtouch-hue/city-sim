# 高速鉄道 要件定義

ヨーロッパの高速鉄道（ICE・TGV・ユーロスターのような）を街に入れる。

## 1. 車両

- 白や銀の流線型。ヨーロッパ風の架空のデザイン（実在の会社のロゴや塗装は使わない）。
- 実寸（先頭車の長い鼻、1両約25m、8〜12両編成）。

## 2. 線路

- 普通の鉄道とは別の、高速鉄道専用の線路。
- 高架が基本で、街の外では地上にも引ける。
- 引き方は普通の線路と同じ（縦横・斜めにドラッグ）。
  - 曲がる所は、大きな半径のカーブで自動的になめらかにする。
  - 急な曲がりは引けない（理由を表示）。
- 見た目：高架橋、架線柱と架線、防音壁（必要な所）。

## 3. 駅

- ターミナル駅：約8×20マス。大きなガラス屋根（ベルリン中央駅のような）。ホーム数本。
- 中間駅：約5×14マス。ホーム2本＋通過線。
- 駅前広場とバスターミナル：駅の前に広場、タクシー乗り場、バス乗り場。

## 4. ゲームの中の役割

- マップの外の街と結ぶ：線路をマップの端まで引くと、ほかの都市からの乗客が来る。商業・オフィスの需要と観光が上がる。
- 駅の周りの地価が上がる：大きな駅の周りが繁華街になる。

## 5. 未定（作る前に決めたいこと）

- ほかの路線（鉄道・地下鉄・高架鉄道・モノレール）や空港駅との乗り換えをできるようにするか。
- 費用・維持費・運賃の目安。
- 街の中の移動（駅が2つ以上あるとき）にも使えるか。
- 騒音の扱い。
